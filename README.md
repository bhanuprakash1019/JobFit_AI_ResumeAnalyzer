# JobFit AI – Job Application Rejection Reason Predictor

## About the Project
JobFit AI is a Machine Learning-based web application that analyzes a candidate's resume against a job description. It helps job seekers identify missing skills, tools, and technologies and understand potential gaps that may affect their suitability for a role.

The application provides skill-matching results and recommendations to help candidates improve their resumes and prepare for job opportunities.

## Features
- Upload and analyze a resume.
- Compare resume content with a job description.
- Identify matched skills and missing requirements.
- Highlight potential skill gaps.
- Recommend skills, tools, and technologies to learn.
- Display analysis results through a web interface.

## Technologies Used
- **Programming Language:** Python
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas
- **Backend:** Flask
- **Frontend:** HTML, CSS, JavaScript
- **Model Storage:** Joblib

## Project Structure
```text
JobFitAI_Premium_UI_Progress/
├── app.py
├── web_app.py
├── requirements.txt
├── templates/
│   └── index.html
├── static/
│   ├── app.js
│   └── style.css
├── src/
│   ├── skill_matcher.py
│   └── recommender.py
├── dataset/
│   ├── hiring_outcomes.csv
│   └── skill_catalog.csv
└── models/
    ├── features.joblib
    └── rejection_model.joblib
```

## Installation and Setup

### 1. Clone the Repository
```bash
git clone https://github.com/YOUR_USERNAME/JobFit-AI.git
cd JobFit-AI
```

Replace `YOUR_USERNAME` with your GitHub username.

### 2. Install Dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Application
If `web_app.py` is the main Flask application, run:

```bash
python web_app.py
```

### 4. Open in Your Browser
Visit:

```text
http://127.0.0.1:5000
```

## How It Works
1. Upload your resume.
2. Enter the job description for your target role.
3. Start the analysis.
4. Review the matching results and potential skill gaps.
5. Use the recommendations to improve your resume and skills.

## Project Objective
The main objective of JobFit AI is to help job seekers understand how their resumes align with job requirements and identify areas for improvement.

**Note:** The tool provides guidance based on its analysis. It cannot determine the actual reason an employer rejected an application or guarantee selection.

## Future Enhancements
- Support additional resume formats.
- Improve skill extraction and matching.
- Add personalized learning resources.
- Enhance model evaluation and recommendation accuracy.
- Deploy the application online.
